# MacBookCam

**Камера MacBook как веб-камера на Windows-ПК по домашнему Wi-Fi.**

[English version](README.md)

![MacBookCam на Windows](docs/screenshot-windows.png)

```
MacBook (значок в строке меню) ── Wi-Fi ──► ПК (окно MacBookCam) ──► «OBS Virtual Camera» ──► любая программа
```

На ПК камера появляется как **OBS Virtual Camera**, поэтому работает в любой программе, где можно выбрать веб-камеру: видеозвонки, стриминг, мессенджеры, браузер.

- **Бесплатно и с открытым кодом** (MIT).
- **До 1080p и 60 к/с**, если камера это умеет. Встроенные камеры MacBook обычно выдают максимум 30 к/с; iPhone через Continuity Camera или USB-камера, подключённая к Mac, — 60.
- **Плавная картинка:** буфер сглаживания выравнивает рывки Wi-Fi, каждый кадр держится на экране одинаковое время.
- **Сам находит Mac**, даже при включённом VPN на ПК. IP можно указать и вручную.
- **Приватность:** камера Mac включается только пока ПК подключён. Видео не выходит за пределы локальной сети.
- Если связь пропала, виртуальная камера продолжает работать с заглушкой и переподключается сама.
- Интерфейс на русском и английском (по языку системы, можно переключить).

## Установка

### Windows-ПК
1. Установите [OBS Studio](https://obsproject.com/download). MacBookCam использует её драйвер виртуальной камеры; запускать сам OBS не нужно.
2. Запустите `MacBookCam-Windows.exe`. Если SmartScreen предупредит о неизвестном издателе: **Подробнее → Выполнить в любом случае**.

### Mac
1. Откройте `.dmg` и перетащите **MacBookCam** в **Программы**.
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует. Один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/MacBookCam.app
   ```
   Или: Системные настройки → Конфиденциальность и безопасность → внизу «MacBookCam заблокирован» → **Всё равно открыть**.
3. Запустите. В строке меню появится значок камеры. На запрос доступа к камере нажмите «Разрешить».

## Использование

1. **Mac:** запустите MacBookCam (значок в строке меню, окна у приложения нет).
2. **ПК:** запустите MacBookCam, оставьте «Автопоиск» (или выберите Mac, или впишите его IP) и нажмите **«Подключить»**.
3. **В нужной программе** выберите камеру **OBS Virtual Camera**.

Держите крышку MacBook открытой (камера в ней) и не давайте Mac уснуть.

### Настройки на ПК

| Настройка | Что делает |
|---|---|
| Разрешение, к/с | Что запросить у Mac. Если камера не тянет нужную частоту, окно об этом скажет. |
| Качество JPEG | Ниже — меньше трафик и чуть меньше задержка. |
| Сглаживание | **Выкл** — минимальная задержка, кадры показываются по приходу. **Авто** — небольшой буфер под измеренную неровность Wi-Fi (рекомендуется). **Сильное** — максимально ровная картинка для нестабильного Wi-Fi ценой большей задержки. |
| Отразить | Зеркалит картинку по горизонтали. |
| Подключаться при запуске | Подключается сразу при открытии. |

В строке статуса видны реальная частота кадров, битрейт, неровность сети, размер буфера и ровность подачи кадров.

### Меню на Mac

Статус и IP (клик копирует), пауза трансляции, выбор камеры (встроенная, iPhone, USB), отключение ПК, автозапуск при входе, язык.

## Если не работает

- **«Mac не найден»:** роутер может блокировать широковещание (гостевые сети, «изоляция клиентов»). Скопируйте IP из меню на Mac и впишите его на ПК.
- **Нет связи даже по IP:** проверьте, что устройства в одной сети, и брандмауэр macOS (Системные настройки → Сеть → Брандмауэр). Если macOS спросит про доступ к локальной сети — разрешите.
- **Ошибка камеры на Mac:** меню на Mac → «Открыть настройки доступа к камере» → включите MacBookCam и перезапустите приложение.
- **«Нет виртуальной камеры» на ПК:** установите OBS Studio. Если OBS запущена со своей виртуальной камерой — остановите её.
- **Рывки или большая неровность:** включите сглаживание «Сильное», снизьте разрешение или качество JPEG, подойдите ближе к роутеру, используйте Wi-Fi 5 ГГц. На Mac известный источник периодических задержек Wi-Fi — радиомодуль AirDrop/Handoff (AWDL); `sudo ifconfig awdl0 down` выключает его до перезагрузки (AirDrop и Handoff на это время не работают).

## Как это устроено

Mac снимает камеру через AVFoundation (выбирая формат камеры с нужной частотой кадров), сжимает кадры в JPEG и отправляет по TCP вместе с метками времени съёмки. ПК распаковывает кадры, показывает каждый по его метке времени плюс небольшой адаптивный буфер и передаёт результат в виртуальную камеру OBS через [pyvirtualcam](https://github.com/letmaik/pyvirtualcam). Mac находится UDP-рассылкой через каждый сетевой адаптер.

Порты: TCP 5005 (видео), UDP 5006 (поиск).

## Сборка из исходников

- **Windows:** `build_windows.bat` → `dist\MacBookCam.exe`
- **Mac:** `bash build_mac.sh` → `dist/MacBookCam.dmg`
- **CI:** GitHub Actions собирает всё при каждом пуше в `main`; тег `v*` публикует релиз.

Консольные версии без интерфейса: `mac_sender.py` (Mac) и `pc_receiver.py` (ПК), параметры — через `--help`. Как настроить разработку — в [CONTRIBUTING.md](CONTRIBUTING.md).
